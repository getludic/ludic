# Security Policy

## Supported Versions

Security fixes are released for the latest version of both maintained streams.

| Version | Python     | Supported |
| ------- | ---------- | --------- |
| 1.x     | 3.14+      | Yes       |
| 0.5.x   | 3.12, 3.13 | Yes       |
| < 0.5   |            | No        |

## Reporting a Vulnerability

Please do not open a public issue or pull request for a security problem.

Report it privately through GitHub instead: open the
[Security tab](https://github.com/getludic/ludic/security) of the repository and
choose **Report a vulnerability**, or go straight to the
[report form](https://github.com/getludic/ludic/security/advisories/new).

It helps to include:

- the affected version,
- a description of the problem and its impact,
- a short example that reproduces it.

A fix is released for both supported streams at the same time, and the advisory is
published once the fixed versions are available. Reporters are credited in the
advisory unless they prefer not to be.
